# @tnsu/ui-kit-vue

Vue 3 UI-kit для приложений ТНСУ. Скопирован из `tansu-lzk/packages/ui-kit` (токены navy/gold V5).

## В Inventory

Пакет лежит в `packages/ui-kit`, frontend подключает через `file:../packages/ui-kit`.

```ts
import { Button, Alert, Sidebar } from '@tnsu/ui-kit-vue';
import '@tnsu/ui-kit-vue/styles.css';
```
